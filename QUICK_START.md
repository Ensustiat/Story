# 🚀 Quick Start Guide

## Super Fast Setup

### Linux/Mac Users
```bash
./install.sh
./run.sh
```

### Windows Users
```cmd
install.bat
run.bat
```

### Manual Setup
```bash
pip install -r requirements.txt
python solana_pnl_tracker.py
```

## What You Need

1. **Your Solana wallet address** (the public key, not private key!)
2. **Internet connection** (for fetching price data)
3. **Python 3.8+** installed on your system

## What You'll Get

📊 **Excel file with 3 sheets:**
- Portfolio Summary (your P&L overview)
- Detailed Positions (complete token data)
- All Transactions (every transaction with prices)
